# PRODIGY_WD_04 – Personal Portfolio Website

This project is a Personal Portfolio Website developed as part of the **Prodigy InfoTech Web Development Internship**.

The portfolio showcases personal details, skills, and projects with a visually appealing layout and background image for enhanced presentation.

## Features
- Responsive portfolio layout
- Background image integrated for better visual appeal
- Sections for personal information, skills, and projects
- Clean and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
The objective of this task was to create a professional personal portfolio to demonstrate web development skills and present projects effectively.
